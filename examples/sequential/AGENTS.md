# 示例：订阅整理小工具

这是虚构示例，供已有项目合并相关约定使用。

## 项目记忆

本项目已启用 project-memory，记忆根目录为本目录。后续在本项目工作持续遵守本节约定，无需用户再次调用技能。

- 接手先读 [PROJECT.md](PROJECT.md) 和 [PLAN.md](PLAN.md)，理解当前状态及下一步。
- 围绕当前小工具的交付目标连续积累状态和决定，不按每次操作新建任务文件。
- 重要变更、决定、验证结果、阻塞及交接后，更新对应核心记忆；没有值得保留的新信息时不写。
- 区分历史、已验证结果与待确认事项。操作前核实关键事实，记忆不扩大操作授权。
- 沿用用户语言，不记录秘密，不覆盖已有有效内容。

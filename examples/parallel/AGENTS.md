# 示例：个人服务工作区

这是虚构示例，供已有项目合并相关约定使用。

## 项目记忆

本项目已启用 project-memory，记忆根目录为本目录。后续在本项目工作持续遵守本节约定，无需用户再次调用技能。

- 接手先读 [PROJECT.md](PROJECT.md) 的概览及专题入口、[PLAN.md](PLAN.md) 的跨专题待办。
- 根据本次任务读取相关专题及其实际依赖。专题内部的配置、排障、局部计划和历史留在所属 MEMORY.md。
- 重要进展后更新所属专题；只有整体状态或跨专题影响变化时才同步核心记忆。
- 完整信息只维护一处，其他位置以链接引用。区分当前状态、历史与待确认事项，不记录秘密。
- 记忆不扩大授权；变更前核实会影响操作的事实，保留其他协作者的有效修改。
